# INC 5000 Companies – Data Visualization Dashboard (2014)

## Project Overview
This project presents an interactive dashboard created using Power BI to analyse the INC 5000 Company List dataset from 2014.

The dashboard helps explore company growth, revenue, industries, and geographical distribution.

**Note:** This project uses historical 2014 data and does not represent current company performance.

## Tools Used
- Microsoft Power BI Desktop
- Power Query / Power BI Data Model
- DAX (Data Analysis Expressions)

## Dataset Information
- Total Companies: 5,000
- Dataset: INC 5000 Company List (2014)
- Source file: Data Set- Inc5000 Company List_2014.csv

## Dashboard KPIs
The dashboard includes four key performance indicators:
- Total Companies
- Average Growth
- Total Revenue
- Average Employees

## Visualisations
1. Top 10 Industries by Company Count
2. Top 10 States by Company Count
3. Revenue vs Growth Scatter Chart

## Interactive Filters
- Industry slicer
- State slicer

These filters allow users to explore the dashboard based on selected industries and states.

## Key Insights
- IT Services is the most represented industry, with 733 companies.
- California has the highest company count, with 694 companies.
- Average company growth is approximately 516.44%.
- Total reported revenue is approximately 215.29 billion.

## Project Files
- `INC5000_Dashboard.pbix` – Power BI dashboard file.
- `screenshots/` – Dashboard screenshots.

## Conclusion
This project demonstrates how Power BI can be used to transform company data into interactive visualisations and meaningful business insights.
